
how to run this on your computer, using node js



step 1, check you have node js installed
open terminal, run:
    npm --version

if you see a version number, npm is installed
if not, download from internet / ual self serve, restart vs code, and try above again



step 2, go to this project
in terminal, type:
    cd 3jstestmap
to go the the project directory

vs code terminal can be accessed by dragging up from bottom of window



step 3, install all packages
in terminal, run:
    npm install

this must be done once on each device first use
the packages are large and not stored on github, this command redownloads all project packages



step 4, run server
in terminal, run:
    node server.js

the server runs in the background, and the page opened later will connect to it when it is activated
the server controls tile data, storing it and getting new data
the page calls the server for a tile, and after it is loaded/fetched, the server returns it to the page



step 5, second terminal
open a second terminal (so you have 2 you can switch between)
do this by clicking plus symbol at top right of terminal



step 6, go to project
in second terminal, type in terminal
    cd 3jstestmap



step 7, web page
in second terminal, run:
    npm run dev
it will return a link if successful, click to visit webpage



server.js keeps running seperately to the webpage
ie. it wont reload with the page, you must close and reopen to apply changes to server.js
you can close it by, in the terminal running it, typing [ctrl] + "c"

the page runs simmilarly to live server
ie. can make changes and reload page on chrome
also, you can quit, pressing q and enter at the same time
and restart with "npm run dev" again, just make sure you "cd" to the project location as above
